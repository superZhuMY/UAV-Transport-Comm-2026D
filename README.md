## 统一计算口径（四问必须一致）

属**统一建模假设**，非题面逐字给定，详见 `01_思路文档/D题求解思路说明.md`：

- 能耗：`E_hor = E_use · d / L(q)`，`L(q) = L0 − (L0 − LF)(q/Q)^1.5`；`E_up = (m + q) · 9.81 · h⁺ / (η · 3.6e6)`；下降不另计；整趟 `E ≤ 0.8 · E_use`，余量仅在整趟上限扣一次。
- 巡航海拔 = 航段所经 DEM 原始像元最高值 + 50 m；服务区作业海拔 = 地面 + 30 m；O01 作业海拔 = 其地面海拔。
- 距离：WGS 84 / UTM 49N 米制直线；DEM 为 PixelIsPoint（像元中心配准），穿格按采样点最邻近 2×2 像元并集保守取高。
- 充电：SOC < 90% 段占等效满充时间 65%，≥ 90% 段占 35%，分段线性；充满前不得复用。
- 交付时刻：同一架次同一停靠点的全部货箱，在整站交接结束后统一记为完成（保守口径）。
- 硬时限 = 医疗物资期望送达时间与首批截止时间取较早者，共 31 箱（3600 / 7200 / 10800 s 分别为 17 / 7 / 7 箱）。
