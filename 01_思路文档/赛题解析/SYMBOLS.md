# 初步符号表

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| $O01$ | 临时调度中心 | 节点 |
| $S_i$ | 第 $i$ 个服务区 | $i=1,\ldots,15$ |
| $G01$ | 位于 $O01$ 的固定网关 | 通信端点 |
| $g$ | 运输无人机机型 | A、B、C，按附件编号复核 |
| $q$ | 航段当前有效载荷 | kg |
| $\rho_g$ | 机型返航安全余量比例 | 0–1 |
| $E^{\mathrm{use}}_g$ | 单组电池可用能量 | kWh |
| $h_{ij}$ | 航段计划巡航海拔 | m |
| $t$ | 自任务起点起算的时刻 | s |
| $\mathrm{SOC}$ | 电池或能源组件荷电状态 | 0–1 |
| $b_{ij}(t)$ | 两端点视线地形遮挡指示 | 0/1 |
| $A_{ij}(t)$ | 双向通信链路可用性 | 0/1 |
| $K$ | 第四问任务组数 | 2 或 3 |

算法变量和目标权重待模型选择后补全，不在拆题阶段预定。
